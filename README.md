# PropGeo

A high-performance geospatial data engine.

## Features
- Real-time spatial indexing
- Geofencing & proximity search
- In-memory storage with persistence
- RESTful API & CLI

## Quick Start

```bash
go install https://github.com/kkanupriyaphd21-dev/prop-geo/cmd/propgeo-cli@latest
```
